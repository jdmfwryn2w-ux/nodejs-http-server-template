# AGENTS.md

This file provides guidance to AI coding agents working in this repository.

## Project Overview

A Node.js HTTP server template that runs on Cloudflare Workers. It uses the built-in `node:http` module to create a server and the `cloudflare:node` `httpServerHandler` adapter to export it as a Workers handler. This demonstrates running standard Node.js HTTP server code on the Workers runtime.

This is a **template** repository (part of `cloudflare/templates`), meant to be copied and customized.

## Tech Stack

- **Platform:** Cloudflare Workers, configured via `wrangler.jsonc`
- **Runtime:** Node.js compatibility via the `nodejs_compat` flag and `cloudflare:node`
- **Server:** `node:http` `createServer`
- **Language:** TypeScript (strict)
- **Tooling:** Wrangler 4 for dev/build/deploy; `@types/node` for Node type definitions

## Project Structure

```
wrangler.jsonc              Worker config: main entry, nodejs_compat, observability
tsconfig.json               Strict TS config (noEmit, Bundler resolution, Node lib)
src/index.ts                Worker entry: createServer + httpServerHandler export
worker-configuration.d.ts   Generated Cloudflare bindings types (do not edit by hand)
```

## Common Commands

All commands run from the repository root.

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` (or `npm start`) | Start local Wrangler dev server |
| `npm run build` | Build via `wrangler build` |
| `npm run check` | `tsc && wrangler deploy --dry-run` |
| `npm run deploy` | Deploy to Cloudflare Workers (`wrangler deploy`) |
| `npm run cf-typegen` | Regenerate `worker-configuration.d.ts` from Wrangler config |
| `npx wrangler tail` | View real-time logs from deployed Worker |

## Conventions & Notes

- **Node.js HTTP pattern:** `src/index.ts` creates a server with `createServer((req, res) => {...})`, calls `server.listen(8080)`, and exports `httpServerHandler({ port: 8080 })` as the default. Routing is done manually via `req.url`. Follow this pattern when adding routes.
- **Required compatibility flags:** `wrangler.jsonc` sets `compatibility_flags: ["nodejs_compat"]` and a recent `compatibility_date`. These are required for `node:http` and `cloudflare:node` to work — do not remove them.
- **Port:** The `8080` passed to both `server.listen` and `httpServerHandler` is symbolic in the Workers context; keep them consistent if you change it.
- **No bundler:** TypeScript is served directly by Wrangler. `tsconfig.json` has `noEmit: true` — type-checking only. Type errors surface during `npm run check` / `tsc`.
- **Generated files:** `worker-configuration.d.ts` is generated by `wrangler types` — run `npm run cf-typegen` to regenerate, do not edit by hand.
- **Observability** is enabled in `wrangler.jsonc`; source maps are uploaded.
- **README note:** The README mentions `wrangler.toml`, but the actual config file is `wrangler.jsonc`. Prefer `wrangler.jsonc` as the source of truth.
